# 箭头挪出核玩工具（arrow-escape-tool）

在线使用：https://ppppan9.github.io/arrow-escape-tool/ （单文件 `index.html`，可离线打开）

复刻参考视频的「箭头挪出」玩法：网格上铺满带箭头的折线，点一条线——箭头前方直到边界没有别的线，它就沿自己的路径蛇形滑出画面；被挡住时线变白、冲到挡路的线再退回（挡路线闪白，画面边框泛红）。顺序随意，自由游玩。

## 功能
- 内置关卡 = 参考视频第 1 帧逐格还原的哆啦A梦（48×50 格、200 条线），可解性检查。
- **▶ 自动通关**：默认「参考视频顺序」——逐帧还原的 27 次点击（含 5 次被挡）、镜头推近与 4 次平移、手指轨迹，之后自动求解直到清空；也可选「纯求解」（0 次点错）或「求解 + 偶尔点错」。
- **✏ 关卡编辑**：拖动画线（尾 → 头，最后一段方向 = 箭头方向）、删除 / 改色 / 反向、改网格尺寸、实时可解检查（卡死的线标红）；关卡 JSON 导入 / 导出；用透明 PNG 自动生成可解关卡；🎲 换一局 = 随机形状可解关卡。
- 所有外观 / 动画 / 镜头 / 音效 / 手指 / 胜利页参数都可在面板中修改并自动保存（带 SETTINGS_VERSION 与迁移）。
- 手指：默认预设 hand.png，可选卡通手或无，上传 PNG 覆盖。
- ⏺ 录制（不随自动通关自动开始）、导出 AE 工程（每条线一个形状图层 + 修剪路径关键帧，镜头空对象）、导出 H5 试玩（8 渠道，无手指，默认不自动演示）。

## 开发
```
npm install
npm run build        # 生成 index.html
npm test             # 综合测试（被挡 / 随机顺序手动清空 / 自动通关 / 胜利页 / 编辑器 / 设置）
npm run test:ae      # AE 导出 + Node 模拟 AE 运行 jsx
npm run test:h5      # H5 8 渠道（H5_QUICK=1 为快速版）
npm run shots        # 与参考视频逐帧对比截图 → screenshots/
```
