# 箭头挪出核玩工具 · AE 工程导出说明

1. 解压 zip，After Effects（2020+）→ 文件 → 脚本 → 运行脚本文件 → 选 `build_ae_project.jsx`（需与 `timeline.json`、`assets/`、`audio/` 同目录）。
2. 脚本新建工程：文件夹「箭头挪出_AE工程」，主合成「主合成_箭头挪出」（尺寸见面板「AE 合成尺寸」，帧率见 timeline.json）。
3. 图层（从下到上）：背景纯色 → 镜头（空对象，位置/缩放关键帧 = 开场推镜与每次平移）→ 底部点阵（PNG）→ 每条线一个形状图层「线_001_青」…（路径 = 线自身折线（圆角为贝塞尔）+ 箭头方向的延长线；「修剪路径」开始/结束关键帧 = 蛇形滑出 / 被挡时冲过去再退回；描边颜色定格关键帧 = 被挡变白 / 恢复）→ 每条线的箭头形状图层「…_箭头」（位置 + 定格旋转）→ 点击波纹（外圈 / 中心点，缩放与不透明度）→ 底部文字 → 胜利页（压暗 + 标题）→ 结束页（如开启）→ 手指（位置 / 按下缩放）。
4. 线条与箭头全部父级到「镜头」，移动镜头空对象即可整体改镜头。
5. 音频：`audio/mix.wav`（含开场配音，若开启）+ 预合成「音效_逐事件」（默认静音，避免与混合音轨叠加；只选“逐事件”时为开启），主合成上有对应标记。

已知限制（如实说明）：
- 线头正好在拐角圆弧内时，AE 的修剪端点与页面上相差不到 0.1 格。
- 被挡线变白、挡路线闪白为颜色定格关键帧（页面上同样是硬切）。
- 胜利页标题为一张 PNG（缩放 + 不透明度），霓虹辉光已烘焙进图片。
- 「只导出被点过的线」模式下，其余线合成在一张静态 PNG 里，不能再单独编辑。
